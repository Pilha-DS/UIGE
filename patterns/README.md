# Patterns

Exemplos canônicos usados para demonstrar **como aplicar** os padrões do projeto.

Diferença:

- `docs/standards/` diz a regra;
- `patterns/` mostra uma aplicação aprovada da regra.

Pastas iniciais:

- `ui/` — componentes e interações recorrentes;
- `architecture/` — exemplos de estrutura;
- `manifests/` — manifests canônicos de referência.
