# Visão do produto

O UIGE fornece interfaces gráficas consistentes para ferramentas originalmente orientadas a terminal.

## Objetivo

Permitir que o usuário descubra, configure e execute ações de ferramentas sem precisar memorizar toda a sintaxe de linha de comando, preservando o poder e a flexibilidade da ferramenta original.

## Filosofia

- simples para executar;
- organizado para trabalhar;
- poderoso para configurar;
- extensível para automatizar.

## Experiência esperada

O usuário deve enxergar principalmente:

- Workspace;
- Ferramenta;
- Ação;
- Perfil;
- Workdir;
- Executar.

Termos internos devem aparecer apenas quando forem úteis em telas avançadas ou de desenvolvimento.

## Não objetivo

O UIGE não deve substituir a ferramenta original, redefinir sua semântica ou inventar opções que ela não possui. Ele deve representar e orquestrar capacidades reais de forma estruturada.
