# Produto

Documentação sobre **o que o UIGE deve fazer**, sem entrar em detalhes de implementação.

Arquivos:

- `vision.md` — objetivo, público, filosofia e limites;
- `features.md` — funcionalidades atuais e planejadas;
- `interface.md` — estrutura da interface: navegação, telas e o que cada uma concentra;
- `flows.md` — fluxos de uso do ponto de vista do usuário;
- `roadmap.md` — capacidades por fase (o quê);
- `implementation-order.md` — ordem recomendada de implementação (quando / como avançar).
