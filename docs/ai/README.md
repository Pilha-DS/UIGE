# Regras para IA e agentes

`AGENTS.md` na raiz é a regra operacional principal. Esta pasta explica os princípios em mais detalhe.

Uma IA que trabalha no UIGE deve:

1. entender a documentação antes de alterar código;
2. identificar a fonte canônica da regra envolvida;
3. fazer a menor mudança suficiente;
4. preservar compatibilidade quando possível;
5. documentar mudanças relevantes;
6. validar o resultado;
7. não inventar decisões arquiteturais silenciosamente.
