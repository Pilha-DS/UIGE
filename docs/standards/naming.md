# Nomenclatura

## Idioma

- nomes internos de código: inglês;
- documentação do projeto: português, salvo necessidade específica;
- texto de interface: linguagem natural para o usuário, evitando expor nomes internos.

## Termos canônicos

Usar consistentemente:

- Tool;
- Manifest;
- Command;
- Parameter;
- Workspace;
- Execution;
- Workflow;
- WorkflowStep;
- Profile;
- Launcher;
- Automation.

## Regra

Não criar sinônimos internos para conceitos já definidos sem ADR. Ex.: não alternar entre `Preset`, `ProfileConfig` e `Profile` para representar a mesma entidade.
