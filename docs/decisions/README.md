# Architecture Decision Records (ADR)

Decisões arquiteturais importantes devem ser registradas aqui.

Nome sugerido:

`0001-titulo-da-decisao.md`

Estrutura mínima:

- Contexto;
- Decisão;
- Alternativas consideradas;
- Consequências;
- Status.
