# Changes

Registro incremental das mudanças relevantes do projeto.

## Regras

- nunca apagar change anterior;
- usar sequência crescente;
- registrar apenas mudanças relevantes, não cada ajuste de formatação;
- referenciar arquivos afetados.

## Template

```markdown
# Mudança

Resumo da alteração.

# Arquivos

- `caminho/arquivo`

# Motivo

Por que a alteração foi necessária.

# Impacto

Compatibilidade, migração ou efeitos relevantes.
```
