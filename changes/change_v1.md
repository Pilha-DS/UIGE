# Mudança

Reorganização inicial da documentação do UIGE, separando especificação de produto, domínio, arquitetura, padrões e regras para IA.

# Arquivos

- `README.md`
- `AGENTS.md`
- `CONTRIBUTING.md`
- `docs/**`
- `patterns/**`
- `.cursor/rules/**`

# Motivo

O README anterior acumulava responsabilidades distintas e dificultava identificar a fonte canônica de cada regra.

# Impacto

Nenhuma funcionalidade foi removida. A especificação anterior foi preservada em `docs/reference/current-specification.md` para migração e conferência.
