# Mudança

Atualização de `docs/standards/ui.md` para o catálogo de componentes (button, modal, form, etc.) com definição de padrões apenas durante o desenvolvimento, em `/patterns/ui/`.

# Arquivos

- `docs/standards/ui.md`
- `patterns/ui/README.md`
- `changes/change_v3.md`

# Motivo

Evitar inventar padrões de UI sem uso real; manter o padrão canônico acoplado à primeira implementação reutilizável.

# Impacto

Nenhuma implementação de UI. Componentes listados ficam pendentes até o desenvolvimento exigir o padrão.
